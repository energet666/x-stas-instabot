# Instagram Downloader Telegram Bot

Этот Telegram бот позволяет скачивать видео (Reels) и фото из Instagram. Бот автоматически оптимизирует видео для корректного воспроизведения в Telegram и поддерживает систему вайтлиста.

## ✨ Особенности

- 📥 **Скачивание из Instagram**: Поддержка Reels, одиночных постов и каруселей.
- 🛠 **Автоматическая оптимизация**: Перекодирование видео через `ffmpeg` (H.264, AAC) для гарантированного воспроизведения в Telegram.
- 🔐 **Система доступа**: Встроенный вайтлист пользователей. Новые пользователи могут запрашивать доступ у администратора.
- 📂 **Постоянное хранилище**: Опциональное сохранение скачанного контента в указанную директорию (для администратора).
- 📜 **Логирование**: Запись всех действий в файл `app.log` и возможность просмотра логов через команду `/log`.

## 🚀 Требования

Для работы бота необходимы следующие установленные инструменты:

1.  **Go** (версия 1.25.2 или выше)
2.  **[gallery-dl](https://github.com/mikf/gallery-dl)** — используется для скачивания контента.
3.  **ffmpeg** — используется для получения метаданных и оптимизации видео.

## 🛠 Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/energet666/x-stas-instabot.git
    cd x-stas-instabot
    ```

2.  Установите зависимости Go:
    ```bash
    go mod download
    ```

3.  Установите системные зависимости (пример для Ubuntu/Debian):
    ```bash
    sudo apt update
    sudo apt install gallery-dl ffmpeg
    ```

## ⚙️ Настройка

Создайте файл `.env` в корневой директории проекта и заполните его:

```env
TELEGRAM_TOKEN=ваш_токен_бота
ADMIN_ID=ваш_telegram_id
COOKIES_FILE=cookies.txt
PERMANENT_STORAGE_PATH=/path/to/storage
CONCURRENT_LIMIT=5

```

### Описание переменных:
- `TELEGRAM_TOKEN`: Токен от @BotFather.
- `ADMIN_ID`: Ваш Telegram ID. Вы автоматически получите доступ к боту и будете получать уведомления о запросах на доступ.
- `COOKIES_FILE` (Опционально): Путь к файлу с куки-файлами для `gallery-dl`. Помогает избежать блокировок со стороны Instagram.
- `PERMANENT_STORAGE_PATH` (Опционально): Путь, куда будут сохраняться все скачанные файлы (только для запросов от администратора).
- `CONCURRENT_LIMIT` (Опционально): Максимальное количество одновременных загрузок (По умолчанию: 5).

## � Получение куки (Cookies)

Instagram часто блокирует автоматические запросы без авторизации. Чтобы бот работал стабильно, рекомендуется использовать файл с куки:

1.  Установите расширение для браузера (например, **"Get cookies.txt LOCALLY"** для Chrome или аналог для Firefox).
2.  Зайдите на сайт [instagram.com](https://www.instagram.com) и войдите в свой аккаунт.
3.  Нажмите на иконку расширения и экспортируйте куки для домена `instagram.com` в формате **Netscape**.
4.  Сохраните полученный текст в файл `cookies.txt` в корневой папке бота.
5.  Убедитесь, что в `.env` указано правильное имя файла: `COOKIES_FILE=cookies.txt`.

## 📖 Использование

1.  Направьте боту команду `/start`.
2.  Отправьте ссылку на Instagram пост или Reels.
3.  Бот скачает контент, оптимизирует его и отправит вам.

### Команды для администратора:
- `/log` — отправить текущий файл логов.
- Уведомления о новых пользователях приходят в личные сообщения с кнопками для одобрения или отклонения доступа.

## 🤝 Системные требования

Бот тестировался на macOS и Linux. Рекомендуется использовать свежие версии `gallery-dl` и `ffmpeg`.
